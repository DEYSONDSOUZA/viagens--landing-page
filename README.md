# 🌿 Amazone-se Tour

**Amazone-se Tour** é um projeto de site institucional voltado para o turismo na Amazônia, com foco em experiências culturais, naturais e sustentáveis na cidade de Manaus (AM).

O projeto foi desenvolvido utilizando **HTML5 e CSS3**, com ênfase em **layout responsivo**, **interações visuais**, **transições suaves** e uma identidade visual inspirada na floresta amazônica.

---

## 🧭 Visão Geral

O site apresenta:

- Uma **homepage com overlay** sobre imagem de destaque
- **Menu de navegação interativo** com efeitos hover
- Seção **TripMe**, com pontos turísticos apresentados de forma intercalada
- Seção **MeetUs**, com mapa integrado e layout responsivo
- Seção **Advice**, com dicas úteis para visitantes
- **Footer institucional**, seguindo padrões profissionais

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**  
- **CSS3**
  - Flexbox
  - Transições e animações (`transition`, `hover`)
  - Layout responsivo
  - Overlay com `position` e `backdrop-filter`

---

## 🎨 Destaques de UI/UX

- 🎯 Overlay centralizado sobre imagem principal
- 🖱️ Animações suaves no menu de navegação
- 🖼️ Efeito de zoom e sombra em imagens ao passar o mouse
- 🔁 Layout intercalado (imagem ↔ texto) na seção TripMe
- 🗺️ Google Maps responsivo e proporcional às imagens
- 🌿 Identidade visual inspirada na Amazônia
